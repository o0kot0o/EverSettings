# EverSettings

A professional, research-driven settings manager for **World of Warcraft: Forever** (interface 16001, build 1.60.1).

EverSettings presents standard Blizzard settings, hidden console variables (CVars) and advanced options in one organised, searchable window, with clear controls, safe staged changes, backups and profiles. It is not just another CVar browser: every editable setting has researched ranges, sources and a verification status, and unknown variables stay read-only until they are researched.

> **Status: Milestone A (foundation) plus UI refinement, alpha.** Offline tested (108 automated tests). Loads in game; slider, validation and external-change sync confirmed in game; the rest of the in-game checklist (#1) is in progress. See [docs/CLAUDE_STATUS.md](docs/CLAUDE_STATUS.md).

## Features (Milestone A)

- 86 curated settings across Graphics, Performance, Camera, Quality of Life, Questing, Interface and Accessibility, each citing Blizzard's Forever UI source or the client's own CVar help text.
- A catalog of all **1,785** Forever CVars and 77 console commands, classified as in Blizzard's settings window (418), used by other Blizzard UI (256) or hidden (1,111).
- Read-only runtime discovery with `ConsoleGetAllCommands()`, which reports variables added, removed or changed since the bundled catalog.
- Numeric settings always get a **slider plus an editable number box** that stay in sync. Typed values are kept exactly, invalid input is flagged, Enter confirms and Escape cancels.
- Staged changes: nothing reaches the game until you press **Apply**. Every write is read back, and the result is reported as applied, adjusted by the client, rejected, failed or restricted.
- External changes (Blizzard options, other addons, console commands) are detected and shown, never overwritten.
- An initial snapshot on first run, the value each setting had before EverSettings first changed it, automatic backups before profiles, undo/redo and change history.
- Profiles: save, save as, rename, duplicate, delete, compare, apply only some categories, and import/export through a checksummed text format that is never executed.
- Combat-safe: secure variables are never written during combat, and protected APIs are never bypassed.
- Never changes a setting on install or login.

## Install

Copy `addon/EverSettings` into `World of Warcraft\_forever_\Interface\AddOns\`, or from a clone of this repository run:

```powershell
.\scripts\deploy.ps1            # copies the addon (auto-detects the Forever install)
.\scripts\deploy.ps1 -Mode link # junction for development: edits are live after /reload
```

In game: `/es` or `/eversettings`. Other commands: `/es diag`, `/es discover`, `/es resetwindow`, `/es help`.

## Development

```powershell
.\scripts\test.ps1              # offline tests (creates .venv with lupa, a Lua 5.1 runtime)
.\scripts\update_catalog.ps1    # refresh the CVar catalog from the research sources
python tests/run_tests.py --coverage   # regenerate docs/COVERAGE.md
```

| Path | Purpose |
|---|---|
| `addon/EverSettings/` | The addon (the only folder deployed to the game) |
| `addon/EverSettings/Database/Definitions/` | Curated, researched setting definitions (data) |
| `addon/EverSettings/Database/Generated/` | CVar catalog generated by `tools/database/import_cvars.py` |
| `tools/database/` | Offline catalog importer and its pinned source data |
| `tests/` | Strict WoW API mock and specs, run through Lua 5.1 |
| `scripts/` | Deploy, test and catalog update scripts |
| `docs/` | Status, plan, architecture, research, schema, UI design, test results, handoff |
